# RetroTailWind

A live sprint retrospective app. The ship's speed measures participation and only goes up during a retro: cards in Sail give half of it, the share of people who vote in Navigate 30%, and owned action items in Set course 20%. Wins and problems set the sea instead: icebergs make it rough but never slow the ship, they melt once someone owns an action for them, and an iceberg that comes back from an earlier retro rises out of the water at once, bigger and grey; back three retros in a row, it turns black (a look only, it doesn't roughen the sea further). Each retro has a named ship and a goal star, five retro phases, action items with owners that carry over, and a logbook. Facilitators also see passive retro health there.

## Run it

It's a single self-contained page. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works).
